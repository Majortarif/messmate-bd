# Security policy

## Reporting a vulnerability

Please email **tarifulhoque347@gmail.com** with the subject `MessMate BD security`. Do
not open a public issue. Include the steps to reproduce, what an attacker could do, and
the affected URL or file.

You'll get a reply within 72 hours. Confirmed issues are fixed as fast as possible, and
you'll be credited in the release notes unless you'd rather not be.

Please test only with accounts and messes you created yourself. Do not access other
people's data, run denial-of-service tests, or spam the contact form.

## Supported versions

Only the latest commit on `main` (the live site) receives fixes.
